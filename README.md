## 🚀 How to Upload to GitHub & Deploy on Vercel

### Step 1: Initialize Git Repository & Push to GitHub

Open terminal inside this project folder (`policy-care-solutions`):

```bash
git init
git add .
git commit -m "Initial commit for Policy Care Solutions website"
```

Create a new repository on [GitHub](https://github.com/new) named `policy-care-solutions`. Then run:

```bash
git remote add origin https://github.com/YOUR_GITHUB_USERNAME/policy-care-solutions.git
git branch -M main
git push -u origin main
```

---

### Step 2: Connect Repository to Vercel

1. Log in to [Vercel](https://vercel.com).
2. Click **"Add New..."** -> **"Project"**.
3. Select your GitHub repository **`policy-care-solutions`**.
4. Leave framework preset as **"Other"** or **"Static Site"**.
5. Click **"Deploy"**.

Vercel will immediately deploy your site with a free `https://policy-care-solutions.vercel.app` URL!

---

### Step 3: Connect Custom Domain on Vercel

1. In Vercel Project Dashboard, go to **Settings** -> **Domains**.
2. Type your domain (e.g., `policycaresolutions.com` or `policycare.in`) and click **Add**.
3. Vercel will display your DNS target records:
   - For Apex Domain: Set **A record** to `76.76.21.21` in your domain registrar (GoDaddy, Namecheap, Hostinger, etc.).
   - For Subdomain (e.g., `www`): Set **CNAME record** pointing to `cname.vercel-dns.com`.
4. Once DNS propagates (1-5 minutes), your site will be live with free SSL (HTTPS)!
